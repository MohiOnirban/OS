09 / 12 — TECHNICAL REVEAL

Inside
the kernel.

A pathname is resolved once when a file is opened. Reading through a descriptor uses the existing open file description, not a fresh lookup of the old name.

10 / 12 — RESOURCE MANAGEMENT

When can
the file die?

The last name can disappear before the last open reference. The OS must retain the original file until both are gone.

*The demo counts one persistent shell reference. Temporary references during reads are omitted. Other kernel references, mappings and snapshots can complicate real storage reclamation.

// Simplified lifecycle rule
if (links == 0
  && refs == 0) {
  reclaim(file);
}
Reclamation ≠ secure erasure.
11 / 12 — REAL-WORLD RELEVANCE

Change the file.
Don't interrupt the reader.

A same-filesystem atomic rename can replace a published pathname with a new file while existing readers keep their old open references.

EXISTING READER

Version A

Continues reading the original open file object.

NEW READER

Version B

Resolves the same pathname to the newly published file.

Another consequence: deleted but open files can still consume storage until their remaining references are released.

12 / 12 — CASE CLOSED

A filename
is not the file.

On UNIX, a file can outlive its last name. Its storage becomes reclaimable only when the remaining references are released.

Verify it in a real terminal

The webpage simulates UNIX file-system operations. Browsers cannot run these shell commands directly without an external backend. Use this isolated experiment on macOS or Linux to verify the behavior. It creates and removes only its own temporary files.

(
  tmp=$(mktemp -d) || exit 1
  cd "$tmp" || exit 1
  printf 'ORIGINAL FILE\n' > ghost.txt
  ls -i ghost.txt
  exec 3<ghost.txt
  rm ghost.txt
  cat ghost.txt
  printf 'NEW FILE\n' > ghost.txt
  ls -i ghost.txt
  cat ghost.txt
  cat <&3
  exec 3<&-
  rm ghost.txt
  cd / && rmdir "$tmp"
)

Expected: the old pathname fails after removal; the new pathname prints NEW FILE, while FD 3 prints ORIGINAL FILE. Actual inode numbers will differ from the symbolic A/B labels.
